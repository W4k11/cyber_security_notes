File Transfer Protocol:
HTTP nin aksine dosya aktarıp almak için kullanılır.

USER alanı, kullanıcı adını girmek için kullanılır. 
PASS, şifreyi girmek için kullanılır. 
RETR (retrieve) komutu, FTP sunucusundan istemciye dosya indirmek için kullanılır. 
STOR (depo) istemciden sunucuya dosya yüklemek için kullanılır.
