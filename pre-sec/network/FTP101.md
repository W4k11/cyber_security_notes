# FTP (File Transfer Protocol) Temelleri

## 1. FTP Nedir?

FTP, iki bilgisayar veya bir sunucu ile istemci arasında **dosya yükleme (upload)** ve **dosya indirme (download)** amacıyla kullanılan en eski ve en temel ağ protokollerinden biridir.

- **Port Bilgisi:** Varsayılan olarak denetim/komut iletimi için **Port 21**, veri aktarımı için ise **Port 20** kullanılır.
    
- **HTTP'den Farkı:** HTTP web sayfalarını, görselleri ve API yanıtlarını tarayıcıya taşımaya optimize edilmişken; FTP büyük ve doğrudan dosya transferleri, dizin yönetimi ve arşivleme işlemleri için tasarlanmıştır.
    

## 2. Temel FTP Protokol Komutları (Arka Planda Çalışan İstekler)

Bir FTP istemcisi sunucuya bağlandığında arka planda şu temel RFC standart komutları döner:

|Komut|Anlamı|Görevi|
|---|---|---|
|**`USER`**|Username|Giriş yapılacak kullanıcı adını sunucuya iletir. _(Örn: `USER anonymous`)_|
|**`PASS`**|Password|Kullanıcının şifresini sunucuya iletir.|
|**`RETR`**|Retrieve|Sunucudan istemciye dosya çekmek/indirmek için çağrılır.|
|**`STOR`**|Store|İstemciden sunucuya dosya kaydetmek/yüklemek için çağrılır.|
|**`TYPE`**|Transfer Mode|Dosya aktarım türünü belirler. Metin belgeleri için `TYPE A` (ASCII), çalıştırılabilir/arşiv/medya dosyaları için `TYPE I` (Binary).|

## 3. Terminal Üzerinden FTP Kullanım Rehberi (Adım Adım)

Linux veya Windows terminalinde standart FTP istemcisi ile bir sunucuya bağlanıp işlem yapma süreci şu şekildedir:

### Adım 1: Sunucuya Bağlanma

Bash

```
ftp 192.168.1.50
```

### Adım 2: Kimlik Doğrulama

Sunucu bağlantıyı kabul ettiğinde sizden sırayla kimlik bilgilerini ister:

Plaintext

```
Name (192.168.1.50:user): w4k11
331 Please specify the password.
Password: *********
230 Login successful.
```

_(Güvenlik testi / CTF ortamlarında genellikle parola gerektirmeyen `anonymous` kullanıcısı ile şifresiz veya rastgele bir e-posta girilerek oturum açılabilir.)_

### Adım 3: Dizin İçeriğini Listeleme

Sunucudaki mevcut dosya ve klasörleri görmek için:

Kod snippet'i

```
ftp> ls
```

### Adım 4: Aktarım Modunu Ayarlama (ASCII vs Binary)

- Düz metin dosyaları (`.txt`, `.html`, `.csv`) için:
    
    Kod snippet'i
    
    ```
    ftp> type ascii
    ```
    
- Görseller, arşivler veya çalıştırılabilir programlar (`.zip`, `.png`, `.exe`, `.elf`) bozulmaması için:
    
    Kod snippet'i
    
    ```
    ftp> binary
    ```
    

### Adım 5: Dosya İndirme ve Yükleme

- **Sunucudan dosya indirmek için (`get`):**
    
    Kod snippet'i
    
    ```
    ftp> get dosya_ismi.txt
    ```
    
- **Sunucuya dosya yüklemek için (`put`):**
    
    Kod snippet'i
    
    ```
    ftp> put yerel_dosya.txt
    ```
    
- **Oturumu kapatmak için:**
    
    Kod snippet'i
    
    ```
    ftp> exit
    ```
    

## 4. Güvenlik Notu: FTP Neden Riskli?

- **Düz Metin (Cleartext) İletişim:** Standart FTP şifreleme (SSL/TLS) içermez. Kullanıcı adı, parola ve aktarılan tüm dosyalar ağ üzerinden açık metin olarak geçer.
    
- **Dinleme (Sniffing) Tehdidi:** Yerel ağda Wireshark çalıştıran bir saldırgan girilen `USER` ve `PASS` değerlerini tek hamlede görebilir.
    
- **Güvenli Alternatifler:** Modern sistemlerde standart FTP yerine **SFTP** (SSH üzerinden, Port 22) veya **FTPS** (FTP over TLS/SSL) kullanılır.
