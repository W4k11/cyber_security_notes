# Veritabanlarına Giriş (Databases 101)

Veritabanları; kolayca erişilebilen, yönetilebilen ve analiz edilebilen **yapılandırılmış veri koleksiyonlarıdır**.

- **Kimlik Doğrulama:** Kullanıcı adı/parola eşleşmeleri (örn. TryHackMe girişleri).
    
- **Sosyal Medya:** Gönderiler, yorumlar ve beğeniler (Instagram, Facebook).
    
- **Öneri Sistemleri:** İzleme ve tüketim geçmişi (Netflix, Spotify).
    

## Veritabanı Türleri

| **Tür**                                        | **Yapı**                                | **En Uygun Senaryo**                                                                    | **Örnek**         |
| ---------------------------------------------- | --------------------------------------- | --------------------------------------------------------------------------------------- | ----------------- |
| **İlişkisel (Relational / SQL)**               | Tablolar, satırlar ve sütunlar          | Tutarlı, sabit formatlı ve veri doğruluğunun kritik olduğu yerler (E-ticaret işlemleri) | PostgreSQL, MySQL |
| **İlişkisel Olmayan (Non-Relational / NoSQL)** | Tablo dışı formatlar (Belge, JSON/BSON) | Değişken veri yapıları ve büyük ölçekli içerik toplama (Sosyal medya)                   | MongoDB           |

**NoSQL Belge Örneği:**

JSON

```
{
  "_id": "4556712cd2b2397ce1b47661",
  "name": { "first": "Thomas", "last": "Anderson" },
  "date_of_birth": "1964-09-02",
  "occupation": ["The One"],
  "steps_taken": 4738947387743977493
}
```

## İlişkisel Veritabanı Mimarisi

- **Tablo (Table):** Belirli bir konudaki kayıtlar kümesi (örn. `Books`).
    
- **Sütun (Column):** Tablodaki her bir özelliğin tanımlandığı alanlar (örn. `id`, `name`, `published_date`).
    
    - **Veri Tipleri:** Sütuna tanımlanan veri tipi dışında giriş yapılamaz (_String, Integer, Float/Decimal, Date/Time_).
        
- **Satır (Row / Record):** Tabloya eklenen her bir bağımsız veri kaydı.
    

## Anahtarlar (Keys)

### 1. Primary Key (Birincil Anahtar)

- Tablodaki her satırı **benzersiz (unique)** şekilde tanımlar.
    
- Bir tabloda yalnızca **bir** adet Primary Key bulunabilir.
    
- _Örnek:_ Üniversite öğrenci numarası veya tablodaki benzersiz `id` sütunu.
    

### 2. Foreign Key (Yabancı Anahtar)

- İki tablo arasında **bağlantı (ilişki)** kurmak için kullanılır.
    
- Bir tablodaki Foreign Key, ilişkili olduğu diğer tablonun Primary Key sütununa işaret eder.
    
- Bir tabloda **birden fazla** Foreign Key bulunabilir.
    

> **İlişki Örneği:**
> 
> `Authors` tablosundaki `id` (Primary Key), `Books` tablosundaki `author_id` (Foreign Key) ile eşleşerek her kitabın hangi yazara ait olduğunu gösterir.

### Veritabanı ve SQL Temelleri

**Veritabanı Yönetim Sistemi (DBMS) Nedir?** Veritabanları pratikte **Veritabanı Yönetim Sistemi (DBMS - Database Management System)** adı verilen yazılımlar aracılığıyla kontrol edilir. DBMS, son kullanıcı ile veritabanı arasında bir arayüz görevi görerek saklanan verileri sorgulama, güncelleme ve yönetme imkânı sunar.

- **Popüler DBMS Örnekleri:** MySQL, MongoDB, Oracle Database, MariaDB.
    

**SQL (Structured Query Language) Nedir?** Kullanıcı ile ilişkisel veritabanı arasındaki etkileşim **SQL** dili ile sağlanır. SQL; ilişkisel bir veritabanında saklanan verileri tanımlamak, sorgulamak ve yönetmek için kullanılan standart bir programlama dilidir.

### SQL ve İlişkisel Veritabanlarının Avantajları

- **Hızlıdır:** Az depolama alanı kullanımı ve yüksek işlem performansı sayesinde büyük veri yığınlarını neredeyse anında döndürebilir.
    
- **Öğrenmesi Kolaydır:** Düz İngilizceye çok yakın bir sözdizimine sahip olduğu için öğrenme eşiği düşüktür; fonksiyonlara ve mantığa odaklanmayı kolaylaştırır.
    
- **Güvenilirdir:** Verilerin kaydedilebilmesi için belirli ve katı kurallar (şemalar) tanımlayarak veri tutarlılığını ve doğruluğunu garanti altına alır.
    
- **Esnektir:** Çok çeşitli sorgulama yetenekleri sunarak kapsamlı veri analizi işlemlerini verimli şekilde yürütmeyi sağlar.

### Veritabanı ve Tablo Komutları (Database & Table Statements)

Bu bölümde veritabanları ve tablolar oluşturmak, listelemek, değiştirmek ve silmek için kullanılan temel SQL komutları yer almaktadır.

### Veritabanı Komutları (Database Statements)

**CREATE DATABASE** Yeni bir veritabanı oluşturmak için kullanılır.

SQL

```
-- Genel Sözdizimi
CREATE DATABASE database_name;

-- Uygulama: 'thm_bookmarket_db' adında veritabanı oluşturma
CREATE DATABASE thm_bookmarket_db;
```

**SHOW DATABASES** Mevcut tüm veritabanlarını listeler. Çıktıda yeni oluşturduğunuz veritabanının yanı sıra MySQL'in çalışmasını sağlayan varsayılan sistem veritabanları (`mysql`, `information_schema`, `performance_schema`, `sys`) da görünür.

SQL

```
SHOW DATABASES;
```

**USE** Üzerinde çalışılacak (aktif) veritabanını seçer. Sonraki tüm tablo ve veri sorguları bu veritabanı üzerinde çalışır.

SQL

```
USE thm_bookmarket_db;
```

**DROP DATABASE** Artık ihtiyaç duyulmayan bir veritabanını tamamen silmek için kullanılır.

SQL

```
-- Genel Sözdizimi (Not: Bu adımda çalıştırmayın)
DROP DATABASE database_name;
```

### Tablo Komutları (Table Statements)

**CREATE TABLE** Aktif veritabanı içinde yeni bir tablo oluşturur. Tablo oluştururken sütun adları, veri tipleri ve kısıtlamalar (constraints) tanımlanmalıdır.

SQL

```
-- Genel Sözdizimi
CREATE TABLE example_table_name (
    example_column1 data_type,
    example_column2 data_type,
    example_column3 data_type
);

-- Uygulama: 'book_inventory' tablosunu oluşturma
CREATE TABLE book_inventory (
    book_id INT AUTO_INCREMENT PRIMARY KEY,
    book_name VARCHAR(255) NOT NULL,
    publication_date DATE
);
```

- **`book_id INT AUTO_INCREMENT PRIMARY KEY`**: Sayısal tam sayı değeridir. `AUTO_INCREMENT` sayesinde her yeni kayıtta otomatik olarak 1, 2, 3 şeklinde artar. `PRIMARY KEY` (Birincil Anahtar), tablodaki her satırı benzersiz şekilde tanımlar.
    
- **`book_name VARCHAR(255) NOT NULL`**: En fazla 255 karakter uzunluğunda metin/rakam alabilir. `NOT NULL`, bu sütunun boş bırakılamayacağını belirtir.
    
- **`publication_date DATE`**: Tarih formatında veri saklar.
    

**SHOW TABLES** Seçili aktif veritabanı içindeki tüm tabloları listeler.

SQL

```
SHOW TABLES;
```

**DESCRIBE (veya DESC)** Belirtilen tablonun sütun yapısını, veri tiplerini ve kısıtlamalarını detaylı olarak gösterir.

SQL

```
DESCRIBE book_inventory;
```

_Örnek Çıktı:_

Plaintext

```
+------------------+--------------+------+-----+---------+----------------+
| Field            | Type         | Null | Key | Default | Extra          |
+------------------+--------------+------+-----+---------+----------------+
| book_id          | int          | NO   | PRI | NULL    | auto_increment |
| book_name        | varchar(255) | NO   |     | NULL    |                |
| publication_date | date         | YES  |     | NULL    |                |
+------------------+--------------+------+-----+---------+----------------+
```

**ALTER TABLE** Mevcut bir tablonun yapısını değiştirmek (yeni sütun ekleme, sütun silme, veri tipini değiştirme veya yeniden adlandırma) için kullanılır.

SQL

```
-- 'book_inventory' tablosuna 'page_count' adında tam sayı sütunu ekleme
ALTER TABLE book_inventory
ADD page_count INT;
```

**DROP TABLE** Bir tabloyu ve içindeki tüm verileri veritabanından kalıcı olarak siler.

SQL

```
-- Genel Sözdizimi
DROP TABLE table_name;
```

### CRUD İşlemleri (Create, Read, Update, Delete)

**CRUD** kavramı; **Create** (Oluştur), **Read** (Oku), **Update** (Güncelle) ve **Delete** (Sil) kelimelerinin baş harflerinden oluşur. Veri yönetimi yapan herhangi bir sistemdeki en temel 4 operasyonu temsil eder.

> Ön Hazırlık: İlgili veritabanına geçiş yapmak için `USE thm_books;` komutu kullanılır.

### 1. Create İşlemi (`INSERT INTO`)

Tabloya yeni satırlar (kayıtlar) eklemek için kullanılır.

SQL

```
INSERT INTO books (id, name, published_date, description)
VALUES (1, "Android Security Internals", "2014-10-14", "An In-Depth Guide to Android's Security Architecture");
```

- **Mantık:** `INSERT INTO` ifadesinden sonra hedef tablo adı (`books`) ve parantez içinde veri eklenecek sütunlar (`id, name, published_date, description`) yazılır. `VALUES` kısmında ise bu sütunlara karşılık gelen değerler aynı sırayla girilir.
    
- _Not: Bu veri zaten tabloda mevcut olduğu için komutu çalıştırmanıza gerek yoktur._
    

### 2. Read İşlemi (`SELECT`)

Tablodaki verileri okumak veya sorgulayarak getirmek için kullanılır.

- **Tüm Sütunları Listeleme (`*`):**
    
    Yıldız (`*`) sembolü tüm sütunların getirilmesini sağlar.
    

SQL

```
SELECT * FROM books;
```

_Örnek Çıktı:_

Plaintext

```
+----+----------------------------+----------------+------------------------------------------------------+
| id | name                       | published_date | description                                          |
+----+----------------------------+----------------+------------------------------------------------------+
|  1 | Android Security Internals | 2014-10-14     | An In-Depth Guide to Android's Security Architecture |
+----+----------------------------+----------------+------------------------------------------------------+
```

- **Belirli Sütunları Listeleme:**
    
    Sadece istenen sütunlar virgülle ayrılarak belirtilir.
    

SQL

```
SELECT name, description FROM books;
```

_Örnek Çıktı:_

Plaintext

```
+----------------------------+------------------------------------------------------+
| name                       | description                                          |
+----------------------------+------------------------------------------------------+
| Android Security Internals | An In-Depth Guide to Android's Security Architecture |
+----------------------------+------------------------------------------------------+
```

### 3. Update İşlemi (`UPDATE`)

Mevcut bir kaydın değerlerini güncellemek için kullanılır.

SQL

```
UPDATE books
SET description = "An In-Depth Guide to Android's Security Architecture."
WHERE id = 1;
```

- **Mantık:** `UPDATE` ile güncellenecek tablo adı (`books`) belirtilir. `SET` ifadesinin ardına değiştirilecek sütun ve yeni değeri yazılır. `WHERE` koşulu ise yalnızca bu kurala uyan satırın (`id = 1`) güncellenmesini sağlar (koşul yazılmazsa tablodaki tüm satırlar güncellenir).
    

### 4. Delete İşlemi (`DELETE`)

Tablodan belirli kayıtları kaldırmak için kullanılır.

SQL

```
-- Not: Bu komutu çalıştırmayın; silme işlemi sonraki pratikleri etkileyebilir.
DELETE FROM books WHERE id = 1;
```

- **Mantık:** `DELETE FROM` ardından tablo adı (`books`) ve silinecek satırı belirten `WHERE` şartı (`id = 1`) gelir. `WHERE` kullanılmazsa tablodaki tüm veriler silinir.
    

### CRUD ve SQL Karşılıkları

|**İşlem**|**SQL İfadesi**|**Açıklama**|
|---|---|---|
|**Create (Oluştur)**|`INSERT INTO`|Tabloya yeni bir kayıt ekler.|
|**Read (Oku)**|`SELECT`|Tablodan kayıtları sorgular ve listeler.|
|**Update (Güncelle)**|`UPDATE`|Tablodaki mevcut veriyi değiştirir.|
|**Delete (Sil)**|`DELETE`|Tablodan belirtilen kaydı/kayıtları siler.|

### SQL Cümlecikleri (Clauses)

Bir **cümlecik (clause)**, işlenen verinin kriterlerini belirleyen SQL ifadesi parçasıdır. Verinin türünü, nasıl getirileceğini veya nasıl sıralanacağını tanımlamaya yardımcı olur.

- `FROM`: Erişilen tabloyu belirtir.
    
- `WHERE`: Hangi kayıtların seçileceğine dair satır bazlı filtre koyar.
    

> Ön Hazırlık: İlgili veritabanını seçmek için `USE thm_books;` komutu kullanılır.

### DISTINCT Cümleciği

Sorgularda yinelenen (tekrar eden) kayıtları eleyerek yalnızca **benzersiz (unique)** değerleri döndürür.

SQL

```
SELECT DISTINCT name FROM books;
```

_Örnek Çıktı:_

Plaintext

```
+----------------------------+
| name                       |
+----------------------------+
| Android Security Internals |
| Bug Bounty Bootcamp        |
| Car Hacker's Handbook      |
| Designing Secure Software  |
| Ethical Hacking            |
+----------------------------+
```

Normal `SELECT *` sorgusunda iki kez listelenen _"Ethical Hacking"_ kaydı, `DISTINCT` sayesinde tek bir satır olarak döner.

### GROUP BY Cümleciği

Birden çok kayıttaki verileri belirli sütunlara göre gruplar. Genellikle `COUNT()`, `SUM()`, `AVG()` gibi toplama (aggregate) fonksiyonlarıyla birlikte kullanılır.

SQL

```
SELECT name, COUNT(*)
FROM books
GROUP BY name;
```

_Örnek Çıktı:_

Plaintext

```
+----------------------------+----------+
| name                       | COUNT(*) |
+----------------------------+----------+
| Android Security Internals |        1 |
| Bug Bounty Bootcamp        |        1 |
| Car Hacker's Handbook      |        1 |
| Designing Secure Software  |        1 |
| Ethical Hacking            |        2 |
+----------------------------+----------+
```

`name` sütununa göre gruplama yapılarak her kitaptan kaçar adet (`COUNT(*)`) olduğu hesaplanmıştır.

### ORDER BY Cümleciği

Sorgu sonucunda dönen kayıtları belirli bir sütuna göre artan veya azalan sırada sıralar.

- **Artan Sıralama (`ASC` - Ascending):** Küçükten büyüğe / eskiden yeniye doğru sıralar (varsayılandır).
    

SQL

```
SELECT * FROM books
ORDER BY published_date ASC;
```

- **Azalan Sıralama (`DESC` - Descending):** Büyükten küçüğe / yeniden eskiye doğru sıralar.
    

SQL

```
SELECT * FROM books
ORDER BY published_date DESC;
```

### HAVING Cümleciği

Gruplanmış veriler (`GROUP BY`) üzerinde filtreleme yapmak için kullanılır.

- **`WHERE` vs `HAVING` Farkı:** `WHERE` koşulu veriler gruplanmadan önce satır bazında filtreleme yaparken, `HAVING` koşulu gruplama ve toplama (aggregation) işlemleri yapıldıktan **sonra** grupları filtreler.
    

SQL

```
SELECT name, COUNT(*)
FROM books
GROUP BY name
HAVING name LIKE '%Hack%';
```

_Örnek Çıktı:_

Plaintext

```
+-----------------------+----------+
| name                  | COUNT(*) |
+-----------------------+----------+
| Car Hacker's Handbook |        1 |
| Ethical Hacking       |        2 |
+-----------------------+----------+
```

İsimlerine göre gruplanıp adetleri sayılan kitaplar arasından sadece adında _"Hack"_ geçen gruplar filtrelenmiştir.

### Cümlecik Özeti

|Cümlecik|İşlev|
|---|---|
|`DISTINCT`|Tekrar eden değerleri kaldırır, benzersiz sonuç verir.|
|`GROUP BY`|Belirtilen sütuna göre satırları gruplandırır.|
|`ORDER BY`|Sonuçları `ASC` (artan) veya `DESC` (azalan) olarak sıralar.|
|`HAVING`|`GROUP BY` ile oluşturulmuş gruplara koşul/filtre uygular.|

# SQL Operatörleri: Mantıksal ve Karşılaştırma

Veritabanı üzerinde mantıksal sorgular ve karşılaştırmalar yaparken veriyi verimli bir şekilde filtrelemek ve işlemek için operatörler kullanılır.

Veritabanı seçimi:

SQL

```
USE thm_books2;
```

## Mantıksal Operatörler (Logical Operators)

Bir koşulun doğruluğunu test eder ve geriye `TRUE` ya da `FALSE` değeri döndürür.

### 1. LIKE Operatörü

Belirli bir sütun içinde özel bir kalıp (pattern) aramak için genellikle `WHERE` ifadesiyle birlikte kullanılır.

SQL

```
SELECT * FROM books WHERE description LIKE "%guide%";
```

- **Açıklama:** `description` sütununda `"guide"` kelimesi geçen tüm kitapları listeler.
    

### 2. AND Operatörü

Sorguda birden fazla koşul belirtir ve **tüm koşullar doğru (TRUE)** olduğunda sonuç döndürür.

SQL

```
SELECT * FROM books WHERE category = "Offensive Security" AND name = "Bug Bounty Bootcamp";
```

- **Açıklama:** Kategorisi `"Offensive Security"` olan **VE** adı `"Bug Bounty Bootcamp"` olan kaydı getirir.
    

### 3. OR Operatörü

Birden fazla koşulu birleştirir ve koşullardan **en az biri doğru (TRUE)** ise sonuç döndürür.

SQL

```
SELECT * FROM books WHERE name LIKE "%Android%" OR name LIKE "%iOS%";
```

- **Açıklama:** Adında `"Android"` **VEYA** `"iOS"` geçen kitapları listeler.
    

### 4. NOT Operatörü

Boolean değerini tersine çevirir; belirli bir koşulun dışındakileri (hariç tutulanları) listelemek için kullanılır.

SQL

```
SELECT * FROM books WHERE NOT description LIKE "%guide%";
```

- **Açıklama:** `description` sütununda `"guide"` kelimesi **geçmeyen** kayıtları döndürür.
    

### 5. BETWEEN Operatörü

Bir değerin belirtilen bir aralıkta olup olmadığını kontrol eder (sınırlar dahildir).

SQL

```
SELECT * FROM books WHERE id BETWEEN 2 AND 4;
```

- **Açıklama:** `id` değeri 2 ile 4 arasında (2, 3, 4) olan kitapları listeler.
    

## Karşılaştırma Operatörleri (Comparison Operators)

Değerleri karşılaştırarak belirlenen kriterlere uyup uymadığını kontrol eder.

|**Operatör**|**Anlamı**|**Açıklama**|
|---|---|---|
|`=`|Eşittir|İki ifadenin birbirine tam olarak eşit olup olmadığını kontrol eder.|
|`!=`|Eşit Değildir|İki değerin birbirinden farklı olup olmadığını test eder.|
|`<`|Küçüktür|Solundaki değerin sağdakinden küçük olup olmadığını kontrol eder.|
|`>`|Büyüktür|Solundaki değerin sağdakinden büyük olup olmadığını kontrol eder.|
|`<=`|Küçük veya Eşit|Solundaki değerin sağdakinden küçük veya eşit olup olmadığını kontrol eder.|
|`>=`|Büyük veya Eşit|Solundaki değerin sağdakinden büyük veya eşit olup olmadığını kontrol eder.|

### Örnek Sorgular

**Tam Eşleşme (`=`):**

SQL

```
SELECT * FROM books WHERE name = "Designing Secure Software";
```

**Eşit Olmayanlar (`!=`):**

SQL

```
SELECT * FROM books WHERE category != "Offensive Security";
```

**Tarihten Önce (`<`):**

SQL

```
SELECT * FROM books WHERE published_date < "2020-01-01";
```

**Tarihten Sonra (`>`):**

SQL

```
SELECT * FROM books WHERE published_date > "2020-01-01";
```

**Tarihe Eşit veya Önce (`<=`):**

SQL

```
SELECT * FROM books WHERE published_date <= "2021-11-15";
```

**Tarihe Eşit veya Sonra (`>=`):**

SQL

```
SELECT * FROM books WHERE published_date >= "2021-11-02";
```
