# Shell nedir?

User'ın OS ile iletişim kurmasını sağlayan yazılımdır.

- Remote System Control: Saldıran kişinin hedef sistemde kod veya yazılım çalıştırması.
- Yetki Yükseltme: Shell de ilk erişim kısıtlıysa yönetici erişimine yükseltmenin yollarını araştırırlar.
- Data Exfiltration: Sistemdeki hassas verileri okuyup kopyalama.
- Persistence and Maintenance Access: Kalıcı erişim elde etmeya çalışmak backdoor kopyalama, kullanıcı kimlik bilgilerini alma gibi.
- Post-Exploitation Activities: Saldırganlar alıcağını aldıktan sonra kullanılamaz hale getirmelerine denir. ÖRN: gizli hesaplar, malware yayma, bilgi silip oluşturma gibi.
- Access Other System on the Network: Ağdaki cihazı ele geçirdikten sonra başka bir cihaza geçmeye çalışması.
